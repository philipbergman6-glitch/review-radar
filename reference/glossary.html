Glossary

The words every lesson uses, defined once. Terms are the project's own; where a term is the course's, the deck is named.

Data

termmeaning here
reviewOne JSON object from All_Beauty.jsonl: rating, title, text, images[], asin, parent_asin, user_id, timestamp (epoch ms), helpful_vote, verified_purchase. Schema: src/common/schemas.py.
parent_asinProduct identifier shared by all variants of one product. The Kafka key and the review→product join key. Match rate 100%.
product metaOne JSON object per product from meta_All_Beauty.jsonl. Contains the dirty price string and the free-form details dict.
schema-on-readKeep details as a raw JSON string in the table; parse the keys you need at query time. Chosen because the keys collide under Spark's case-insensitive resolution.
dev category / full categoryAll_Beauty (701,528 reviews, what everything runs on) vs Beauty_and_Personal_Care (~23M, ruled out).
the profiledocs/phase0-profile.txt: measured numbers for the dev category. Quote it, do not recall it.

Streaming

termmeaning here
replay producerReads the JSONL from disk and sends each line untouched to Kafka at a controllable rate. Simulates a firehose deterministically.
topic / partition / offsetKafka's log. reviews.raw has 6 partitions; (partition, offset) uniquely identifies a record and is stored in bronze. Deck 4.
keyThe bytes Kafka hashes to pick a partition. Here parent_asin, so one product's reviews land on one partition. Buys locality, not time order.
acks=all, idempotenceProducer settings: wait for all in-sync replicas; no duplicates on internal retry. Both taught verbatim in deck 4.
KRaftKafka's built-in metadata quorum replacing ZooKeeper. Zero mentions in the decks.
micro-batchSpark Structured Streaming's unit of work: a bounded slice of offsets processed as one batch. Deck 3.
triggerWhen the next micro-batch starts. once (availableNow: drain and stop) or an interval like 5s.
maxOffsetsPerTriggerRecords per micro-batch. The memory throttle: 150,000 for the bulk load.
checkpointDirectory where Spark records which offsets each batch covered. Survives a kill; on restart the job resumes from it. checkpoints/bronze_reviews_raw.
exactly-once (EOS)No loss and no duplicates across a restart. Held by checkpoint offsets plus the Iceberg sink skipping an already-committed batch id. Proven by make eos.
failOnDataLossBronze option: crash if needed offsets aged out of Kafka rather than skip silently.

Lakehouse

termmeaning here
bronze / silver / goldRaw as landed / cleaned and typed / aggregated for use. On the deck-3 lakehouse slide verbatim; "medallion" is not.
IcebergOpen table format: metadata files + manifests over Parquet, giving ACID snapshots, schema evolution, time travel. Not a course technology.
snapshotOne committed state of an Iceberg table. Listed via table.snapshots; each streaming micro-batch commit is one.
catalogue (JDBC)Where Iceberg stores "which metadata file is current" per table. Here a Postgres table iceberg_tables.
MinIOS3-compatible object store holding the bucket lakehouse. Substitute for HDFS.
fanoutIceberg writer mode keeping one open writer per partition so unsorted rows across a midnight boundary do not fail.
time travelReading an earlier snapshot: VERSION AS OF. Shown by make verify.

Search and AI (planned)

termmeaning here
BM25Elasticsearch's default lexical ranking. Deck 5 teaches it and says "no semantic understanding".
analyzer / inverted indexHow text becomes searchable terms. 54 analyzer mentions in deck 5; an explicit mapping earns full credit.
embedding384-dim vector from all-MiniLM-L6-v2 per review text. ~374 reviews/s on this host.
kNN / dense_vectorES vector field and nearest-neighbour query. Available on the basic licence.
hybrid search / RRFFuse BM25 and kNN rankings. Server-side RRF is Enterprise-only in 8.17, so fuse client-side: Σ 1/(60+rank).
aspect sentimentLLM labels each review by aspect (e.g. scent, price) with a polarity; validated against a labelled subset with a threshold set in advance.
RAGRetrieve relevant reviews (kNN) then have the LLM answer a question grounded in them.
gateA phase's pass check. Must print a number.
